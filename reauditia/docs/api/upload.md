# Carga de ficheros mediante integración

<span id="upload"></span>
<span id="post--api-upload (Ejemplo)"></span>

La forma habitual de cargar ficheros es utilizar un formulario o una regla de [subida automática](../panel/subida_automatica.md).

Si tu organización dispone de una integración propia, utiliza únicamente las instrucciones y credenciales entregadas para esa integración. No reutilices datos de acceso entre entornos ni los incluyas en capturas, incidencias o documentación compartida.

## Comprobación funcional

Tras enviar un fichero:

1. Confirma que la integración lo ha aceptado.
2. Localízalo en [Estado de los ficheros](../panel/estado_audios.md).
3. Espera a que alcance un estado final.
4. Consulta el formulario o informe correspondiente.

Esta guía pública no expone direcciones privadas ni mecanismos internos de autenticación.
