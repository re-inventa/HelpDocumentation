# Consulta de consumo

<span id="logs"></span>
<span id="post--api-logs (Ejemplo)"></span>

El historial de consumo se consulta desde [Cartera](../panel/cartera.md). Allí puedes revisar el saldo, filtrar operaciones y descargar la información disponible para tu cuenta.

Las integraciones que necesiten consultar esta información deben usar exclusivamente el contrato entregado a la organización. La guía pública no contiene direcciones privadas ni datos de autenticación.
