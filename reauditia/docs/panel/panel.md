# Panel

El panel ofrece una vista rápida de la actividad disponible para tu cuenta. Sirve para comprobar de un vistazo el volumen procesado y acceder al resto de apartados.

Según la configuración pueden aparecer datos como:

- evaluaciones realizadas;
- preguntas o comprobaciones ejecutadas;
- tiempo o volumen procesado;
- accesos directos a formularios y resultados.

Los datos respetan el alcance de tu usuario y organización. Si el panel está vacío, comprueba primero que existen ficheros finalizados dentro del periodo consultado.
