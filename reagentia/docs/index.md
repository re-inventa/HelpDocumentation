# Reagentia

Reagentia permite preparar procesos documentales, configurar los agentes que participan, cargar los documentos necesarios y seguir cada ejecución hasta obtener sus resultados.

La plataforma es reutilizable y configurable para distintos procesos y organizaciones.

## Cómo empezar

1. Consulta los [conceptos y el alcance](funcional/conceptos.md).
2. Revisa los [casos de uso y ejemplos sintéticos](funcional/casos-de-uso.md).
3. Comprueba qué puedes hacer según tus [roles y permisos](funcional/roles-permisos.md).
4. Sigue la [guía funcional](funcional/index.md) para configurar y lanzar una ejecución.
5. Consulta el [estado y las limitaciones](estado/index.md) antes de utilizar una capacidad nueva.

## Principios del producto

- Cada organización conserva su configuración, conexiones, documentos y ejecuciones de forma aislada.
- Un workflow publicado fija las entradas, los pasos y los resultados esperados.
- Una ejecución ya iniciada conserva la configuración con la que fue creada.
- Las acciones disponibles dependen del rol y del estado actual del trabajo.
- La documentación pública utiliza ejemplos sintéticos y evita información interna o datos reales.
